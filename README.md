# EasyCode

Platform Pembelajaran Koding Python & Berpikir Komputasional Berbantuan AI Adaptif untuk Kurikulum KKA SMA Kelas X.

## Struktur Proyek (Monorepo)

- `/docs` — Dokumen Spesifikasi (`SRS.md`), Desain Sistem (`SDD.md`), dan Pedoman UI/UX (`design.md`).
- `/frontend` — Aplikasi klien berbasis Next.js & Tailwind CSS.
- `/backend` — Layanan REST API, AI Orchestrator (Gemini), dan Code Sandbox berbasis FastAPI.

## Alur Kerja Git (Branching & Commits)

- `main` — Cabang rilis produksi yang stabil.
- `develop` — Cabang integrasi utama untuk pengembangan fitur.
- Prefix cabang kerja: `feature/`, `bugfix/`, `hotfix/`.
